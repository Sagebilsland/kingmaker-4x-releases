# Kingmaker 4X Releases

This repository contains installable release artifacts for the Kingmaker 4X Foundry VTT module. The private development workspace, tests, campaign data, and working history are not published here.

## Install in Foundry VTT

In **Configuration and Setup → Add-on Modules → Install Module**, paste this manifest URL:

https://github.com/Sagebilsland/kingmaker-4x-releases/releases/latest/download/module.json

Future versions can be installed with Foundry's normal **Check for Update** control.
